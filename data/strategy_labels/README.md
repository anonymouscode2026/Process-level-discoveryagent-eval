# Strategy labels — postproc'd

This directory holds the 18-label strategy annotations (per Appendix A.1)
applied to each step of each shipped trajectory. Files mirror the
`data/trajectories_sample/` layout one-for-one:

```
data/strategy_labels/postproc/<model>/<task>/<level>__run<k>.labels.json
```

The 25 files here match the 25-trajectory sample in
`data/trajectories_sample/` and let you re-render the case-study figure and
recompute behavioral metrics without downloading the full corpus.

Generated by `scripts/relabel_strategies.py` followed by
`scripts/postproc_labels.py` (see REPRODUCE.md Tier 2).
